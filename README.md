# Telegram Web Pro (Vite + Express + Socket.IO + MongoDB)

## Ishga tushirish tartibi

### 1. Backend (Server)
```bash
cd server
npm install
npm start
```
*(Eski ma'lumotlarni yangi tuzilishga o'tkazish uchun: `npm run migrate`)*

### 2. Frontend (Vite)
```bash
cd client
npm install
npm run dev
```
